# 眾神殞落（垂直切片 v0.5）

回合制文字冒險 RPG 的可玩版本：一座會隨世界改變的地城（灰燼地窖，3 層＋兩階段 Boss）、4 名可選角色、完整戰鬥與戰報、雙人羈絆與黑盒子研究、記憶簿、模板短演出、營火談話、詞綴裝備。

純前端、零依賴、零建置也能跑；所有角色與數值皆為**測試用**，非正式設定。

## v0.6.1 新增

- 記憶：首次觀察到黑盒子（未解析）效果時寫一筆 `bond_oddity` 記憶，只記事實（傷害數字取自事件），不揭露效果名稱與數值；營火「聊聊最近的戰鬥」可引用。

## v0.6.0 新增

## v0.5.1 新增

## v0.5 新增

- **死裡逃生記憶**：戰鬥結束時仍站著、HP ≤ 20% 最大值的隊員，會寫入一筆記憶（引用最後一次傷害事件、數字等於結束快照、每人只記一次）。營火談話「聊聊最近的戰鬥」會引用它。

- **詞綴與稀有度（P07）**：掉落的裝備可能帶 0–2 個詞綴（鋒利／精準／迅捷／堅固／強韌）。每多一個詞綴稀有度升一級（普通→精良→稀有→史詩）。越深的樓層、餘燼回流時越容易出詞綴（掉落表在 `AFFIX_TABLE`）。物品 ID 仍是字串（`hunter_bow~keen~precise`），舊存檔直接相容。
- **分解**：背包裡用不到的裝備可在營地分解換金幣（普通 5／精良 10／稀有 20／史詩 35），需頁內二次確認。
- **淨化**：小梅的「治癒」會依序移除 1 個負面狀態（灼燒→流血→虛弱），寫成 `status_removed` 事件並引用來源治療事件；驗證器會擋下沒有治療來源的偽造淨化。均衡／守護戰術會主動淨化。
- 存檔讀取時會檢查所有物品 ID，未知物品一律拒絕。

## v0.6

- 抵抗詞綴「耐火」（防具）：灼燒持續傷害減半（捨去、最少 1），減免寫進該次傷害事件的 `calculation`，詳細戰報顯示，驗證器擋下偽造減免。
- 背包「裝備給…」選單顯示各角色同部位的屬性差；背包可依取得順序／稀有度／部位排序（只影響顯示）。

## 本地遊玩

```bash
npm run serve          # 或任何靜態伺服器
# 打開 http://localhost:8080
```

或先 `npm run build`，直接雙擊 `dist/index.html`（單一檔案，可離線）。

## 測試

```bash
npm test               # 單元測試 29 項（重播、快照重算、統計、安全白名單、黑盒子、記憶、演出、存檔、Boss 階段、世界改變、營火談話、詞綴、分解、淨化、死裡逃生記憶）
npm run balance        # 批次平衡模擬（每個種子連續 5 次遠征）
npm install && npx playwright install chromium
npm run e2e            # 瀏覽器端對端 45 項：桌機＋手機
npm run build && npm run e2e:dist   # 測打包後的單檔
```

## 上架到 GitHub Pages

1. 在 GitHub 建立 repo，推上 `main`。
2. Settings → Pages → Source 選 **GitHub Actions**。
3. 之後每次推到 `main`，`.github/workflows/ci-pages.yml` 會先跑全部測試，通過才部署 `dist/`。

## 結構

```text
src/rng.js        決定性亂數（可存檔）
src/data.js       角色、技能、敵人、地城（含世界狀態）、奇遇、羈絆、裝備、詞綴與掉落表
src/engine.js     戰鬥引擎（唯一權威；append-only 事件、指令白名單、Boss 階段、淨化、重播、一致性驗證）
src/report.js     戰報：結算／簡易／詳細／統計／HP 曲線（純函式）
src/memory.js     結構化記憶（只寫規則判定的重大事實）
src/narration.js  模板短演出（只引用真實事件；宿敵與階段轉換用作者文本）
src/talk.js       營火談話（受限意圖選單；只引用真實記憶與統計）
src/game.js       遊戲狀態：營地、遠征、世界狀態、掉落與詞綴、分解、戰後結算、訓練場、存讀檔
src/ui.js         介面
scripts/build.mjs 打包成單一 HTML
```

## 設計原則（摘自專案文件）

- 引擎是唯一權威；戰報、演出、記憶、談話都只讀事件紀錄。
- 一致性驗證不通過就不寫存檔。
- 雙人羈絆只算兩人；換第三人不影響老搭檔；旁觀演出不產生數值。
- 黑盒子：隱藏效果的實際數值一定出現在戰報裡，只是顯示「未解析效果」，要靠訓練場對照實驗確認。
- 玩家指令只接受 `{skill_id, target_id}`；營火談話只接受 `{actor_id, intent}`；其他一律拒絕。
