## 版本紀錄

### v0.6.0（2026-10-24）
- **T1 耐火詞綴：完成。** `AFFIXES.fireproof`（僅防具、mods 空）；`RESISTS` 對照表。戰鬥開始時角色帶 `resist_ids`（寫進 BattleRecord，重播一致）。灼燒 `status_tick` 傷害減半（捨去、最少 1），`calculation` 有 `resist_ids`、`resisted`；`verifyRecord` 重算並擋下偽造或對不上的減免。詳細戰報顯示「耐火減免 n」。掉落沿用 AFFIX_TABLE，只是防具詞綴池多一項。既有單元測試沒有因 seed 改變而失效，不需換 seed。已重跑 `npm run balance`：只有第 5 次 95%→94%，其餘與 v0.5.1 相同（腳本不裝備耐火，影響僅來自詞綴池抽籤）。測試涵蓋有／無耐火、最少 1、重播、偽造被擋、itemDef 解析、武器回傳 null、詳細戰報。
- **T2 裝備比較與背包排序：完成。** 「裝備給…」選項顯示屬性差（例「阿德（攻 +2、速 +1、暴 +4）」、「相同」、空部位列全部屬性）；背包排序（取得順序／稀有度／部位）只改顯示，以原始索引操作裝備與分解。純函式 `statDiffText`、`inventoryOrder` 有單元測試；E2E 驗證比較數字、三種排序、排序後裝備與分解正確、375px 無水平捲動。
- **T3 治療救起瀕死隊友記憶：完成。** `heal_save`（key `heal_save:<pair>`），治療前 HP < 30%、治療者≠目標、隊友才記；引用該次 `heal_applied` 事件，文字數字取自事件。門檻抽成 `NEAR_DEATH_PCT = 30`，與 guard_save 共用。營火「聊聊最近的戰鬥」治療者與被救者各有一句模板。測試涵蓋 29%／30%／自己治療自己／去重／event_id／舊存檔可讀。
- 任務單 2026-10-23（重排版）：T1／T2／T3 全部完成。推送權限 可。
