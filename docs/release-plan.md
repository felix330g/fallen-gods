# 眾神殞落 release plan

所有角色與數值皆為測試用；正式設定以 Claude 專案「ai 文字遊戲」設計文件為準。

## 版本紀錄

- v0.5：新增「死裡逃生」記憶（HP ≤20% 仍站著），營火談話引用；建立本文件。
- v0.4：Boss 第二階段、餘燼回流（世界改變）、營火談話與好感、回報問題資訊。
- v0.3 以前：戰鬥引擎、戰報、羈絆與黑盒子、記憶簿、模板演出、訓練場、存讀檔。

## 平衡數據（npm run balance，300 種子×5 次遠征，v0.5）

- 通關率：第 1 次 68%／第 2 次 55%／第 3 次 63%／第 4 次 76%／第 5 次 88%
- 餘燼回流通關率 69%；平均回合 7.2；Boss 進入第二階段率 99%
- v0.5 未改動任何戰鬥數值，與 v0.4 相同。

## 下一步（優先順序）

1. 更多記憶類型（例：首次治療救起瀕死隊友、首次打出黑盒子效果的「觀察到」記憶）。
2. 營火談話：同一記憶不同好感層級的台詞變化。
3. 第二座地城或第二條路線（需先確認設計）。
4. 戰報匯出（JSON）供回報問題使用。
