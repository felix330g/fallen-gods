# 實作 Roadmap 與驗收

## 分階段交付（M0–M6，v0.3 起均已有可玩實作；M4 只有模板與失敗回退）
1. **M0 規格與資料**：角色／技能／狀態／事件 schema、決定性規則、1 份 fixture。驗收：可手工檢查每次 HP 改變。
2. **M1 戰鬥引擎**：回合排序、技能、狀態、勝負、固定 seed、事件日誌。驗收：同 seed 完全一致；輸入錯誤不會破壞存檔。
3. **M2 戰報查看器**：一般結算、逐回合詳情、統計與狀態、篩選／跳轉。驗收：統計等於逐事件加總；所有回合可查。
4. **M3 短演出（先模板）**：個人、雙人、旁觀、里程碑演出。驗收：不捏造擊殺者、不超篇幅、可略過。
5. **M4 AI 短演出**：受約束的事實包、JSON 驗證、fallback。驗收：斷網仍有報告；prompt injection 無法改屬性。
6. **M5 羈絆研究**：雙人經驗、專屬規則、隱藏 modifier、戰術筆記。驗收：新人入隊不影響既有雙人能力；不同編隊可復現差異。
7. **M6 記憶與整合**：重大事件存檔、後續對話引用。驗收：重要事實不重複；重讀存檔一致；普通玩笑不會變成正式身世。

## 驗收測試矩陣
| 範圍 | 測試 | 預期 |
|---|---|---|
| 重播 | 同 seed＋輸入＋版本多次執行 | 事件與統計一致 |
| 行動 | 速度相同、角色死亡、缺魔、CD 中 | 有明確規則與事件 |
| 傷害 | 暴擊、抗性、護盾、超殺、DOT | 數值可回算，來源可追溯 |
| 狀態 | 疊層、刷新、驅散、抵抗、到期 | 每回合前後快照正確 |
| 統計 | 殺敵、傷害、承傷、治療、機率 | 與原始事件一致；分母正確 |
| 篩選 | 角色／技能／異常／回合 | 指向正確 event_id |
| 演出 | 旁觀者、首次擊殺、宿敵決戰 | 只引用授權事實、不劇透 |
| 記憶 | 多次回看同戰報 | 重要記憶最多寫入一次 |
| 羈絆 | 替換第三人，保持 A-B 原配置 | A-B 默契不變 |
| 黑盒子 | 未解鎖效果生效 | 實際數據真實，來源適度隱藏 |
| 安全 | 惡意對話注入命令 | 不能篡改數值、獎勵、劇情 |
| 失效 | AI 逾時／輸出格式錯誤 | 自動使用模板，不阻塞戰報 |

## 工作方式
修改任何模組時，先指出受影響的資料契約與相依模組，修改後執行相關測試。不要虛構已通過的測試；只記錄實際執行結果。
